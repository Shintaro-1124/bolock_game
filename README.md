# おせわ配送パズル

9×9の盤面にブロックをドラッグして配置する、全200ステージのブラウザゲームです。ステージ報酬でお世話アイテムを獲得し、キャラクターの満腹度・清潔度・ご機嫌を保てます。

## 遊び方

1. 「パズルで遊ぶ」からステージを選びます。
2. 画面下のブロックを9×9の盤面へドラッグして配置します。
3. 縦または横の1列を埋めると、その列が消えます。
4. ステージごとのスコア、ライン消去、荷物回収などの条件を達成するとクリアです。

スマートフォンとPCのブラウザに対応しています。外部API、バックエンド、ビルドツール、npm、外部ライブラリは使用していません。

## GitHub Pagesでの公開方法

このリポジトリは、リポジトリ直下の `index.html` を入口とする静的サイトです。ビルド作業は不要です。

1. GitHub上でリポジトリの **Settings** を開きます。
2. 左メニューの **Pages** を開きます。
3. **Build and deployment** の Source で **Deploy from a branch** を選びます。
4. Branch を **main**、フォルダを **/(root)** にして保存します。
5. デプロイ完了後、表示された公開URLを開きます。

## セーブデータ

進行状況はブラウザの `localStorage` に端末内保存されます。

- 保存キー: `carePuzzleSaveV1`
- 保存形式: JSON
- 保存項目:
  - `stars`: 所持スター数
  - `hunger`: 満腹度
  - `clean`: 清潔度
  - `mood`: ご機嫌
  - `unlocked`: 解放済みステージ
  - `items`: 各お世話アイテムの所持数
  - `lastCare`: 最後にお世話状態を更新した日時

保存キーとデータ構造は既存版から変更していません。同じオリジン上で公開URLを変更しなければ、同じブラウザ・端末のセーブデータを引き続き利用できます。ブラウザのサイトデータ削除、シークレットモードの終了、端末やブラウザの変更を行うと、セーブデータは引き継がれません。

## ファイル構成

- `.nojekyll`: GitHub PagesでJekyll処理を無効化
- `README.md`: ゲーム概要、公開方法、セーブ仕様
